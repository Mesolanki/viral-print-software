# Viral Print Software - Server

Backend server for the Viral Print Software built with Node.js, Express, and Prisma.

## Structure
- `src/config/`: App configuration (db, env, jwt)
- `src/controllers/`: Request handlers
- `src/services/`: Business logic layer
- `src/repositories/`: Database abstraction layer
- `src/routes/`: Router mappings
- `src/middlewares/`: Express middlewares
- `src/validators/`: Input validation schemas
- `src/utils/`: Common utilities
- `src/prisma/`: Prisma schema configuration
